## 1. 本质
从静态和动态两种角度来解决多个设备通信发生冲突的办法。动态的解决办法，类似于死锁预防和死锁避免。可以联合起来看。


## 2. 结构/组成
### 静态信道划分
可以理解为将一个信道逻辑上划为几个信道，供多个设备使用。该方法==不会产生冲突==，但是信道利用率较低。
1. 频分复用（FDM）
   每个设备用一个频率进行通信，所以每一个频率之间需要加入==隔离带==，然后合并为==总频率==，使用==模拟信号==。一般要求==信道的频率带宽要大于子信道频率总和==。
   ![](<Pasted image 20260601203006.png>)
2. 时分服用（TDM）
   将传输时间分为一个个时间片，也叫==TDM帧==（和数据帧无关）。再将每个TDM帧分为等长的时隙，每个设备占用固定的==时隙==。即每个设备只能在固定的时间发送。适合传输==数字信号==。一般要求==介质的位速率要大于单个信号的位速率==（也就是比特的传输速率）。
   ![](<Pasted image 20260601203359.png>)
   由于某些设备在自己的时隙内容，不发送数据，所以总体的信道利用率不高。产生了==统计时分服用（STDM）==，也是异步时分复用。
   ![](<Pasted image 20260601203551.png>)
3. 波分服用（WDM）：了解即可，是对光信号的服用。
4. **码分服用**（CDMA）：区别CSMA，即载波监听的英文缩写。
   将发送一比特的时间，分为m个短的时间间隔，也叫作==码片==。每个设备都有自己码片序列代表0或者1，对其取反就是传输1或0，要求码片序列对自己正交内积为1，对取反的码片序列正交内积为-1，对其它设备的码片序列正交内积为0。
   ![](<Pasted image 20260601204607.png>)
   当接收端收到叠加的码片序列后，用每个设备的码片序列正交内积后，就可以得到正确的比特信息。
   ![](<Pasted image 20260601204756.png>)
### 随机访问控制
思想是不再划分信道了，而是允许用户发送信息时，占用整个共享信道，从而容易导致碰撞。
针对有线网络，是CSMA/CD，即载波监听加上碰撞检测。针对无线网络，是CSMA/CA，即载波监听加上碰撞避免。
#### ALOHA协议：想发就发，随机重发。
没有脑子，从而有了时隙ALOHA协议，要求设备在每个时隙开始时发送信息，同时要求发送一帧的时间要小于时隙。
![](<Pasted image 20260601205345.png>)
#### CSMA协议：
只会在发送前进行监听，不会边发边听，当发生冲突时，会随机等待一段时间，重新监听信道。由此产生了三种数据发送策略。
![](<Pasted image 20260601205634.png>)
对于坚持策略，产生冲突的概率较大，但是更及时，响应时间短。对于非坚持策略，和坚持策略相反。对于p-坚持，注意会有==时间片==，==综合前两种策略的优点==。
#### **CSMA/CD协议**：加上了碰撞检测机制。
争用期：指的是A设备发送一个数据帧到最远的设备B时发生了碰撞，到A设备检测到这个冲突的时间为**争用期**，若过了这个时间，说明该数据帧正确发送完毕。所以最小帧长公式为`最小帧长=争用期*传输速率`。一般==以太网的最小帧长为64B==。同时注意，题目中==100Base==—T设备指的时传输速率为100Mbps。争用期为传播时延的2倍。
![](<Pasted image 20260601210756.png>)
当发送数据帧的时候监测到了碰撞，除了停止发送数据外，还会发送==32bit或48比特的人为干扰信号==。——即为==强化碰撞==。
当检测到碰撞后，使用==截断二进制指数退避算法==来确定重传的时间。重传次数越多，则发生碰撞的概率越小。但是当重传次数到达16次后，说明发送数据的站点过多，放弃该帧，并报告出错。
![](<Pasted image 20260601211218.png>)
注意当一个站点发送完一个数据后，为了让接收站能做好准备，还规定了帧间最小间隔。
![](<Pasted image 20260601211540.png>)
使用该协议的前提是，**==共享介质+半双工==**。
#### CSMA/CA协议
适用于无线网络，用于解决无线信号传播时==衰减快==以及==隐蔽站==的问题。所以该协议不适用碰撞检测，而是采用碰撞避免的策略。
![](<Pasted image 20260601212102.png>)
在该协议中用到以下==帧间间隔==，一般`STFS<PIFS<DIFS`。注意该协议，建立在==停止等待协议上==。
![](<Pasted image 20260601212432.png>)

采用了==虚拟载波监听==，会将设备自己占用信道的时间写入数据帧首部，等同于每个站点自己的NAV。在该时间内，不允许其它设备发送信息。
![](<Pasted image 20260601212827.png>)
当设备发生冲突，推迟接入过了一个DIFS后，设备不会立马发送数据帧，而是进入==争用期==，该争用期由许多时隙构成。同时使用**退避算法**，该算法和CSMA/CD的退避算法相比，就是==增大了退避时间的范围==。每个设备分配的退避时隙数不一样。
![](<Pasted image 20260601213321.png>)
使用**信道预约**可以进一步减少碰撞。本质利用虚拟载波监听的方法，分别在==发送方中的RTS==和==接收方的CTS==声明要占用的信道的时间。用来==解决隐蔽站的问题==。该方法不是强制的，一般用于数据帧过长时。
![](<Pasted image 20260601213608.png>)
#### 轮询访问介质控制
采用了==令牌==机制，注意设备使用完一次令牌后（发送一次数据帧），会重新生成一个令牌，然后在环路中循环访问。
在物理拓扑上可能不属于环形网路，但是==逻辑上属于环形网络==，因此当一个结点出现故障时，整个网络都无法使用。
![](<Pasted image 20260601214319.png>)
