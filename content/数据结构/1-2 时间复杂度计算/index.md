## 1. 本质（是什么）

时间复杂度用来估算某个程序所需要的执行时间，在一定程度上反映了该程序的优劣。

重点在于该如何简便计算出来。

## 循环方式
1. 注意循环内的变化方式：
![循环变化量](<Pasted image 20260707154324.png>)

2. 万能原则：
==外层循环次数`*`内层循环次数==。
	若第二层循环是依据第一层循环，则不能这样处理，如
```
	for(i=1;i<n;i*=2)

    for(j=0;j<i;j++)
        sum++;
```
该程序的复杂度为O(n)。原因在于其总的执行册数为2^p-1，而外层执行了p次，关系为2^p要大于n，则总的时间复杂度为O(n)。

## 递归型
一般画出递归树来，树的深度一般为n，关键在于看每一层的执行次数。

## 常见模型
1. O(n)类
```
for(i=1;i<n;i++)


void foo(int n,int x,int y){
	int z-0;
	if(n<=0){
		z=x+y;
	}else{
		foo(n-1,x+1,y);
		foo(n-1,x,y+1);
	}
}
```
2. O(logn)类
```
for(i=1;i<n;i*=2)
```
3. O(n^2)类
```
for(i=1;i<n;i++)
    for(j=1;j<n;j++)
```
4. 变异O(n)类
```
for(i=1;i<n;i*=2)
    for(j=1;j<i;j++)
```
5. 根号模型
```
while(sum<n)
    sum+=i;

或者

while(i*i<n)
    i++;
```
