**重点**

  

## 1. 本质
解决芯片容量不够，使芯片叠加使用，从而扩展容量；同时为了解决快速传输信息，从而使用并行技术。






## 2. 结构/组成
### 位扩展
称为**字长扩展或者数据总线扩展**，最简单，应将片选信号都连接在一起。如利用`256K*1位`构造`256*8位`，片选信号应都连接在一起，同时共用一样的地址。
![](<Pasted image 20260825144111.png>)
每给出一个18位地址，==所有存储芯片就各提供8位数据总线中的一位数据==。
### 字扩展
称为**容量扩展或者地址线扩展**。低位地址用于确定具体地址，高位地址用于确定具体芯片。
1. 线选法：当高位某一位为0时，选择对应的芯片。线路简单，但是==地址空间不连续==，没有充分利用。
![](<Pasted image 20260825144606.png>)
![](<Pasted image 20260825144625.png>)
2. 片选法：使用了片选译码器，地址空间连续。
![](<Pasted image 20260825144823.png>)
![](<Pasted image 20260825144835.png>)
### 字位扩展
==应先进行位扩展，再进行字扩展==。
![](<Pasted image 20260825145044.png>)

如图所示，最终存储器的容量为`64K*8位`。
### 并行系统
改善主存速度方法：
1. 提高芯片本身速度，如使用==SDRAM技术==。
2. 采用并行结构技术。如==双端口存储器，多模块存储器==。
3. 在CPU和主存间增加==高速缓冲存储器==（如cache）。
### 多模块存储器
CPU取一个数据的过程，如下图所示：
![](<Pasted image 20260825145837.png>)
则需要的==总时间为T1+T2+T3==。
注意在计算存储器带宽时，只用管T2，即花了多少时间准备数据。
1. 高位多体交叉
地址在模块内连续，但是无法实现并行技术。
![](<Pasted image 20260825150020.png>)
![](<Pasted image 20260825150144.png>)
即如果CPU要读取n个存储字，则需要nT时间。
2. 低位多体交叉（轮流启动方式）
==低位地址用于片选，高位地址用于选择模块内具体的存储单元==。
![](<Pasted image 20260825150425.png>)
![](<Pasted image 20260825150450.png>)
这种方式称为**轮流启动**方式，要求==存储周期T<=mr==（m为模块数，r为总线周期）。
当要读取n个存储字，则需要==T+(n-1)r==的时间。==平均读出一个数据的时间为r==。
3. 同时启动方式
所有模块一次读写的位数等于数据总线位数，则使用同时启动方式。
