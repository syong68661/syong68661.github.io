## 1. 本质
存储器不仅包括构成主存，还有辅存，即由磁盘、固态硬盘等构成。它们的特点是容量大，但是存取速度慢。






## 2. 结构/组成
### 磁盘
1. 分为磁盘驱动器、==磁盘控制器（这才是核心，属于IO控制器）==、磁头和盘片等组成。
2. 磁盘的读取是==以扇区为单位==。
3. 磁盘容量
	一般而言，格式化后的容量要比非格式化容量要小。
4. 存取时间
	==寻道时间：取平均值。==
	==旋转时间：根据转速算一周的时间，然后取平均值。==
	传输时间。
5. 磁盘地址结构：注意==磁头号和盘面号是一样的==。
![](<Pasted image 20260825155503.png>)
### 磁盘阵列
口诀：==0无冗余，1全镜像；2海明码，3奇专验；4块集中，5块循环==。
0. 只追求速度。采用交叉编址，因此有了条带。
![](<Pasted image 20260825160309.png>)
1. 增加镜像，提高可靠性。
![](<Pasted image 20260825160445.png>)
2. 用海明码码校验，具备纠错功能，所以==按位交叉==，而前两个是以一个块为条带单元（==块级条带==）。图中深色为校验盘。
![](<Pasted image 20260825160745.png>)
3. 奇偶校验，有一个专用校验盘。
![](<Pasted image 20260825161005.png>)
4. 从位变成块，==条带单元通常为一个扇区==。仍然是集中校验。
![](<Pasted image 20260825161121.png>)
5. 将校验信息循环分散。
![](<Pasted image 20260825161259.png>)
### 固态硬盘
1. 由多个闪存芯片（充当磁盘驱动器）和闪存翻译层（充当磁盘控制器）组成。
![](<Pasted image 20260825161527.png>)
2. 以页为单位进行读写，但是写入时需要擦除（以块为单位）。
3. 一个块的写入次数不能过多。
4. 磨损均衡：
	动态：写时自动选择新的区域。
	静态：更为先进。
