## 2. 结构/组成

### DRAM的工作原理
DRAM由MOS管和电容构成。该组成容易读出时，电容没有电荷，所以需要==再生==；同时电容容易漏电，所以需要不断==刷新==。
![](<Pasted image 20260813162517.png>)
这样一个构成了存储元，多个存储元共用一个地址形成存储单元。
![](<Pasted image 20260813162633.png>)
注意SRAM由于使用了双稳态触发器，所以==不需要刷新和再生，但是其集成度低==。
![](<Pasted image 20260813162834.png>)
### 译码方式
1. 线选法
	使用容量小的静态存储器。

2. 双译码法
	==DRAM一般使用行列地址复用技术==，而SRAM使用行列独立技术。如下图`16*4bit`的芯片。注意其具有行缓冲。
![](<Pasted image 20260813163132.png>)
### DRAM刷新
- 刷新以行为单位，刷新一行的时间一般为存取周期。再生仅仅恢复被读出的单元数据。
- 刷新对CPU透明。
- 若存储器由多个芯片构成，则所有芯片同时按行刷新。

分为三种刷新方式：
1. 集中刷新：产生较长时间的死区。CPU长时间不能访问存储器。
![](<Pasted image 20260813163628.png>)
2. 分散刷新：将存储周期时间变长，但是刷新过于频繁，不适用于高速存储器。
![](<Pasted image 20260813163745.png>)
3. 异步刷新：结合前两种方式，将每一行的刷新分散到这2ms内。更常用，避免CPU等待太长时间。
![](<Pasted image 20260813163958.png>)
### ROM
1. MROM 掩模式：在生产过程中直接写入。
2. PROM 一次可编程：写入后无法改变。
3. EPROM 可擦除可编程：可多次改写，但次数有限，且写入时间长。
4. Flash 闪存：写入前必须擦除。常用于U盘。
5. SSD 固态硬盘
### SDRAM（同步）
- 传统DRAM与CPU之间使用异步方式交换数据，在这期间，CPU只能等待。
- SDRAM使用同步方式，采用突发传输方式，且其行缓冲器由SRAM构成。具体细节在总线章节。
