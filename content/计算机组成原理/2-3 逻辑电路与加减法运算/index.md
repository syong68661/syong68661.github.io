### 补码加减法运算与溢出判断
对于n位机器数。有以下规则：
![](<Pasted image 20260811143244.png>)
即做减法时，可以转换为做加法。
溢出判断有三种方法：
1. 符号法：正+正得负/负+负得正
2. 进位法：符号位进位不等于最高数位进位，即溢出
3. 双符号法：
	00：没有溢出
	11：没有溢出
	01：正溢出。即得到的结果比最大值还大
	10：负溢出。即得到的结果比最小值还小
### 标志寄存器PSW
由ALU生成标志信息，保存到PSW中。
![](<Pasted image 20260811144202.png>)
- 零标志ZF：结果为0时置1。用于==有符号和无符号==。
- 溢出标志OF：判断==有符号数溢出==。公式为符号位进位异或最高数位进位得到结果。
- 符号标志SF：结果最高位。判断==有符号数正负==。
- 进/借位标志CF：判断==无符号数进位/借位==。在加法CF=1，表示进位；减法CF=1，表示借位。公式为Sub异或Cout。
### 加减法运算器
![](<Pasted image 20260811144702.png>)
工作逻辑：
	sub=0,表示加法。B直通。cin为0。
	sub=1，表示减法。输出~B。cin为1。等价于变补运算。
在x86架构中，不管变量是无符号数还是有符号数，==对应的加、减指令（ADD、SUB、MOV）都一样，都是在同样的电路中运行==。
### 比较逻辑
1. 无符号数：基于CF、ZF标志
	`A==B`：结果为0，ZF=1
	`A>B`：结果非0，且无借位，所以CF=0，ZF=0
	`A<B`：结果非0，有借位，所以CF=1，ZF=0
2. 有符号数：基于OF、SF、ZF标志
	`A==B`：结果为0，OF=0，SF=0，ZF=1
	`A>B`：结果非0且符号与溢出标志一致，OF异或SF=0，ZF=0
	`A<B`：结果非0且符号与溢出标志相反，OF异或SF=1，ZF=0
3. 混合类型比较
	对于==常见的int和unsigned int混合运算时，int会转换为unsigned int==，因此负数可能会被解释为较大的无符号数。

### 模4补码
定点小数补码，本质为模2补码，表示范围为`[-1,1)`，当使用双符号位时，变为模4补码，即模长变为4。
可以这样记：

| 类型   | 补码形式    |
| ---- | ------- |
| 定点整数 | 模 2n 补码 |
| 定点小数 | 模 2 补码  |
