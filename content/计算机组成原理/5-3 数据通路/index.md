## 2. 结构/组成
### 数据通路中的原件
#### 组合逻辑元件(操作元件)
输出仅由输入决定,==不受时钟控制==.
![](<Pasted image 20260828163617.png>)
#### 存储元件(状态元件,时序逻辑)
==输入==由时钟控制,==输出==可随时读取.即在每个时钟下降沿,才可以写入数据.
![](<Pasted image 20260828163930.png>)
![](<Pasted image 20260828164017.png>)
在该通用寄存器组中:
	读端口:2个,RA/RB寻址,组合逻辑,不需要时钟.
	写端口:1个,RW寻址,WE控制,时序逻辑,需要==时钟触发==.

### 数据通路组成规律
状态元件---->组合逻辑元件----->状态元件
![](<Pasted image 20260828164417.png>)

### 由基本操作翻译控制信号
四类基本操作
1. 主存单元内容→寄存器    M(MAR)--->MDR
2. 寄存器数据→主存单元    (MDR)->M(MAR)
3. 寄存器间传送/送至ALU输入端    (R0)--->A
4. 算术/逻辑运算,结果→寄存器     (R1)+(A)--->AC

根据基本操作翻译为控制信号:
1. 数据从哪里出，就写谁out
2. 数据到哪里去，就写谁in
3. 中间经过ALU，就写ALU操作控制信号
4. 涉及主存，就考虑MAR、MDR、Read/Write

### 数据通路的基本结构
共有三种分为专用,单总线,多总线三种.
### 专用数据通路
部件==分散连接==,各部件拥有独立专用通路,互不共享.
![](<Pasted image 20260828165120.png>)
### 单总线数据通路
![](<Pasted image 20260828165215.png>)
即CPU内部所有寄存器,ALU挂载到一条公共内部总线.由于共享传输介质,所以==同一时刻仅一个部件可以向总线发送数据==.
区分==CPU内部总线==和==存储器总线==.

#### 典型操作周期数
1. 寄存器间传送:*1个时钟*.控制信号为:Rin,Rout.
2. 算术逻辑运算:*3个时钟*.==由于ALU是组合逻辑电路,没有记忆功能==,所以==需要暂存器A==来存放一个操作数,运算结果临时放在寄存器AC中.控制信号如下:
	① Rlout, Ain
	②ROout, add, ACin
	③ACout, ROin
3. 主存器读:*3个时钟*.要送地址--->读入MDR--->写回寄存器.控制信号如下:
	① R1out, MARin
	②MemR, MDRinE
	③ MDRout,R0in
4. 主存器写:*3个时钟*.


> [!NOTE] 由以上可知,单周期数据通路,无法实现单周期cpu.



#### 判断是否可以合并操作
判断一个时钟周期内是否可以合并多个基本操作:
1. 可以合并:==没有在同一总线上同时要求两个部件输出,且不存在必须先后完成的数据依赖==.比如一个操作访存,另一个操作使用CPU内部通路.
2. 不能合并:同一总线上有两个部件输出;或者先后操作有依赖关系.

#### 设置暂存器A与累加器AC:
1. **避免总线冲突.**
2. ==ALU没有记忆功能.==
3. AC保存ALU的输出.
### 多总线数据通路
![](<Pasted image 20260829142522.png>)
1. 拥有多条内部总线.
2. 可以同时传输多个操作数,减少总线冲突.
3. ==指令执行步骤减少,三操作运算可以在一个时钟内完成==.

> [!NOTE] 考前摇一摇
### 控制信号
#### CU常见输入
1. 时序信号/节拍信号
2. IR:操作码,寻址方式字段,寄存器编号字段
3. FR:零标志,符号标志,溢出标志
4. 必要时还有中断,异常等状态反馈.
#### CU常见输出
1. 寄存器输入控制信号
2. 寄存器输出控制信号 
3. ALU操作控制信号 
4. 移位器操作控制信号 
5. MUX选择信号 
6. 主存Read/Write信号
