3.1 数据链路层的功能

关于数据链路层的基础功能。

易错

1. 本质

从数据链路层，阐述了本层需要完成的功能。分别是封装成帧、透明传输和差错检测。

下面适配器的功能由进一步阐述了。

2. 结构/组成

适配器

物理层的链路仅仅就是一个链路，当在数据链路层加上对应的==协议（由软件和硬件组成）==时，就成为了==数据链路==。 其网卡就可以看为一个适配器，实现该层协议：

  1. 拥有自己的处理器和存储器，所以在内部进行串行通信；外部并行通信。
  2. 当接收错误帧时，进行丢弃；当接收到正确帧时，通过==中断机制==，让计算机进行处理。
  3. 当计算机要发送数据时，适配器对上层的IP数据报进行==封装成帧==。
  4. 计算机的==MAC地址==存储在适配器中（自己的存储器里面）；其==IP地址==由计算机自己存储。

封装成帧

  1. 物理层传输的是比特流，所以数据链路层为了识别对应的数据，要进行帧定界。
  2. 通常在首部放入控制信息，如源MAC地址、目的MAC地址；在尾部放入校验信息。
  3. 该层规定了每个帧最大可以传输的数据上线，成为==最大传送单元MTU==。

透明传输

为了使得上层数据可以进行任意传输，而不用注意数据的格式，所以该层要通过填充技术来实现==透明传输==。

  1. 字节填充法（需要SOH–帧开始符，EOT–帧结束符，ESC–转义字符）。
  2. 字符填充法：使用一个字节在每个帧前面注明该帧所占的字节数（包括计数字节本身） 要区分字节和字符二者。==当计数字节本身出错时，后续的帧会连续出错==。
  3. 零比特填充法：当出现5个连续的1，就要在后面添加一个0。==易于用硬件实现==。
  4. 违规编码法：类比曼彻斯特编码，当==出现编码冗余==的情况时，使用冗余的编码充当填充符号。

差错检测

检错编码

  1. 奇偶校验码：对应出现奇数个1，或者偶数个1。 当为奇数时，注意求检验位和判断是否出错时，对数据进行异或运算后，==还要进行非运算==。 当出现偶数个错误时，该编码无法检测出其中的错误。

  2. 循环冗余检测：产生的帧检验序列FCS一般放在帧尾部。用硬件完成，所以速度很快。 根据多项式，得出除数；根据除数的位数-1（即检验位r)，得到需要在原有数据后面补上几个0。 当进行相减时，实际上进行的是==异或运算==。 当出现单个错误时，可以检验所有位；当检验位数是r时，可以检验连续小于等于r长度的错误。

纠错编码——海明码

  1. 根据图片可知，海明码的每一位对应的==组属性是唯一==的，所以海明码既可以检测出错误，也可以进行纠错。
  2. 每一个检验位Pi,对应一个组，所以公式Pi，对应海明码为H2^(i-1)，也可以进行图示快速画出来。
  3. 当有k个组时，说明有k个检验位，也就说说明有2^K种情况，所以要包含本来数据的位数+检验位+1（对应没有出错的情况）<=2^K。
  4. 根据分组是采用奇校验还是偶检验，来确定检验位。也说明了其本质是进行了多次的奇偶检验。

码距和校验

在编码集中，取最小的二进制位不同的个数为==码距==。说明了当一个编码出现一位错误时，距离正确的编码还有几个距离。

  1. 当d=1时，该编码不具有检测错误的能力。
  2. 当d>=e+1时，说明可以进行e位的检测错误的能力。
  3. 当d>=2t+1时，说明可以进行t位的纠正错误的能力。 从这里可以得出，为了使得海明码可以进行2位检错，进行1位纠错，设计了扩展海明码，其==码距位4==。

传输差错

除了有比特差错外，还有帧差错：

  1. 帧丢失
  2. 帧重复
  3. 帧无序 对于通信质量好的线路，不要求可靠传输（需要具备帧编号、确认和重传机制）；对于通信质量不好的线路，才要求可靠传输。
