3.4 局域网

主要了解在数据链路层，关于有线网络和无线网络中，数据帧的格式

重点 易错 易混

1. 本质

局域网一般跨越了物理层和数据链路层。从不同的数据帧出发，了解传统以太网，无线网络。

2. 结构/组成

数据帧

不同的协议，具有不同的数据帧格式。常见有==以太网帧——802系列==，HDLC协议（已经从考纲中删除），==PPP协议==。下面介绍的都是802系列。

有线网络

帧格式——802.3帧

传统以太网的标准为802.3格式。将数据链路层分为逻辑链路控制==LLC子层==和和媒体接入控制==MAC子层==。 虽然以太网具有CSMA/CD，流量控制与可靠传输，但是以太网的MAC协议提供的是无连接不可靠的服务。注意这里理解可靠的含义：

目前广泛应用的以太网，只有MAC层协议，没有LLC协议。同时使用的MAC帧是==V2标准==。 前导码的8字节由前同步码（7字节）和帧开始定界符（1字节）组成。这里帧定界采用的是==违规编码法==，即以曼彻斯特编码为基础。 对于数据帧最小帧长为64B（是由CSMA/CD协议的争用期决定），最大帧长为1518字节。 对于帧检验序列==FCS==，使用的是循环冗余检测，检验除了前导码外的所有信息。 对于MAC地址，分为单播，组播，广播三种。 说明了局域网标准对应与物理层和数据链路层。

以太网技术
